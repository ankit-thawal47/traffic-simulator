# Every run reports the same fixed result set, labelled as an uncalibrated estimate

Every run, for every scenario, reports the same measures: vehicles through, mean travel time, mean delay per vehicle class, longest queue per approach, and stuck-vehicle count. Each is shown as an absolute number and as a change from the baseline, and every result carries an "uncalibrated estimate" label. We chose this because a published review of the Hebbal flyover study faulted it for reporting different measures per scenario, for percentages that hid small absolute gains, and for undisclosed calibration.

## Consequences

- A scenario-specific measure is not added to one scenario's results; it is added to the fixed set for all, or not at all.
- Stuck vehicles are a headline result, not a hidden repair.
