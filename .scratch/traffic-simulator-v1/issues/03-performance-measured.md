# 03: Performance measured

**What to build:** A measured answer to whether the performance target holds: 3,000 vehicles on the network at once, at least 5 times faster than real time, with two 3D views open. The target in the spec is revised from the measurement.

**Blocked by:** 01

**Status:** done (merged to integration branch; to be repeated after junctions and after visual polish)

- [x] A repeatable measurement reports simulated seconds per real second at 1,000, 3,000 and 5,000 vehicles, engine alone
- [x] The same is measured with one and with two 3D views drawing
- [x] The machine and browser used are recorded with the figures
- [x] The spec's performance target is confirmed or revised, with the reason written down
- [x] If the target is missed, the chosen response (smaller network, shorter period, or optimisation) is recorded
